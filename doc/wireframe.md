# 질문그룹 관리 Wireframe

대상 기능 : 관리자 > 질문그룹 관리

관련 요구사항 : `요구사항명세서.md` > `3.2 질문그룹 관리`

---

# 1. 화면 목적

관리자가 질문을 카테고리별로 묶기 위한 질문그룹을 등록, 조회, 수정, 삭제한다.

질문그룹 예시

- 어린 시절
- 학교생활
- 가족
- 친구
- 결혼
- 직장
- 부모
- 인생철학

---

## 2.2 질문그룹 등록 화면

경로 예시

```text
/admin/question-groups/new
```

와이어프레임

```text
┌──────────────────────────────────────────────────────────────┐
│ Admin                                                        │
├──────────────┬───────────────────────────────────────────────┤
│ Dashboard    │ 질문그룹 등록                                  │
│ 질문 관리     │                                               │
│ 질문그룹 관리  │ ┌───────────────────────────────────────────┐ │
│ 북타입 관리    │ │ 그룹명                                      │ │
│ 출판 관리      │ │ [어린 시절                              ]   │ │
│              │ │                                           │ │
│              │ │ 설명                                       │ │
│              │ │ [유년기와 성장 과정에 대한 질문 그룹       ]   │ │
│              │ │                                           │ │
│              │ │ 정렬순서                                    │ │
│              │ │ [1                                      ]   │ │
│              │ │                                           │ │
│              │ │              [취소]   [저장]               │ │
│              │ └───────────────────────────────────────────┘ │
└──────────────┴───────────────────────────────────────────────┘
```

입력 항목

- 그룹명
- 설명
- 정렬순서

유효성

- 그룹명은 필수 입력이다.
- 정렬순서는 숫자만 입력할 수 있다.
- 동일한 그룹명은 중복 등록할 수 없다.

저장 후 이동

- 저장 성공 시 질문그룹 목록 화면으로 이동한다.
- 저장 실패 시 입력 폼 상단 또는 해당 필드 하단에 오류 메시지를 표시한다.

# 3. 삭제 확인

질문그룹 삭제 버튼 클릭 시 확인 모달을 표시한다.

와이어프레임

```text
┌──────────────────────────────────────┐
│ 질문그룹 삭제                         │
├──────────────────────────────────────┤
│ 이 질문그룹을 삭제하시겠습니까?          │
│                                      │
│ 그룹명 : 어린 시절                     │
│ 연결된 질문 수 : 20                    │
│                                      │
│ 연결된 질문이 있는 경우 삭제할 수 없습니다. │
│                                      │
│              [취소]   [삭제]          │
└──────────────────────────────────────┘
```

삭제 정책

- 연결된 질문이 없는 질문그룹만 삭제할 수 있다.
- 연결된 질문이 있는 경우 삭제 버튼을 비활성화하거나 삭제 실패 메시지를 표시한다.
- 사용 이력이 있는 질문그룹은 실제 삭제보다 비활성 처리를 검토한다.

# 5. 데이터 매핑

## QuestionGroup

| 화면 항목 | DB 필드 | 설명 |
|---|---|---|
| ID | id | 질문그룹 PK |
| 그룹명 | name | 질문그룹 이름 |
| 설명 | description | 질문그룹 설명 |
| 정렬순서 | sortOrder | 목록 및 질문 생성 시 정렬 기준 |

## 파생 표시 항목

| 화면 항목 | 산출 기준 |
|---|---|
| 연결 질문 수 | Question.questionGroupId 기준 count |
| 연결된 질문 목록 | Question.questionGroupId 기준 조회 |

# 6. 기본 사용자 흐름

## 등록

```text
질문그룹 목록
→ 질문그룹 등록 클릭
→ 그룹명, 설명, 정렬순서 입력
→ 저장
→ 질문그룹 목록
```

## 조회

```text
질문그룹 목록
→ 상세 클릭
→ 질문그룹 상세 확인
→ 연결된 질문 목록 확인
```

## 수정

```text
질문그룹 상세
→ 수정 클릭
→ 값 수정
→ 저장
→ 질문그룹 상세
```

## 삭제

```text
질문그룹 상세
→ 삭제 클릭
→ 삭제 확인
→ 연결 질문 없음
→ 삭제
→ 질문그룹 목록
```

# 7. 구현 참고

- MVP에서는 관리자 인증이 적용된 이후 접근 가능한 화면으로 구현한다.
- 목록 기본 정렬은 `sortOrder` 오름차순으로 한다.
- 정렬순서가 동일한 경우 `name` 또는 `createdAt` 기준 보조 정렬을 적용한다.
- 질문그룹은 질문, 북타입과 연결되므로 삭제 전 참조 여부를 반드시 확인한다.
- 모바일 화면에서는 사이드 메뉴를 상단 메뉴 또는 접이식 메뉴로 전환한다.
