# 1. 프로젝트 개요

## 1.1 목적

'나의 이야기'는 사용자가 질문에 답변을 작성하여 자신의 이야기를 기록하고,
이를 하나의 책(PDF) 형태로 출판할 수 있는 웹서비스이다.

서비스 관리자는 질문을 관리하고,
사용자는 원하는 질문집(Book Type)을 선택하여 자신의 이야기를 작성하고
최종적으로 PDF 형태로 저장 및 출판할 수 있다.

# 3.3 북타입 관리

## 목적

- 배우자는 없고 자녀가 있는 사람
- 배우자와 자녀가 없는 사람

- 목록
- 상세

수정

---

Step1

북타입 선택

예)

- 부모님 이야기
- 나의 자서전
- 나의 싱글 라이프

---

Step2

입력항목

- 책 제목
- 보내는 사람

---

Step3

- 작성시간 안내
- 개인정보 안내

---

질문 생성

사용자는

- 질문 수 확인
- 목차 확인

후 생성 완료

# 7. 개발 제약사항

## 개발 환경

본 웹서비스는 초기 개발 및 MVP 배포 시 아래 환경을 기준으로 구현한다.

- Frontend/Backend : Next.js
- 배포 : Vercel Hobby Plan
- Database : Supabase PostgreSQL Free Plan
- Auth : Supabase Auth
- Storage : Supabase Storage
- PDF 생성 : Next.js API Route 또는 Server Action 기반 PDF 생성

---

## 비용 제약

- 초기 개발 및 MVP 운영은 무료 플랜에서 가능한 범위 내에서 진행한다.
- 사용량 증가 또는 성능 요구사항 증가 시 유료 플랜 전환을 고려한다.
- 유료 전환 후보
  - Vercel Pro
  - Supabase Pro

---

## 기술 제약

- 데이터 모델은 Supabase PostgreSQL의 관계형 테이블 구조를 기준으로 설계한다.
- 사용자 인증, 관리자 권한 분리, 파일 저장은 Supabase 기능을 우선 활용한다.
- HTTPS, CI/CD, CDN은 Vercel 기본 제공 기능을 활용한다.
- PDF 생성 기능은 MVP 단계에서는 서버리스 함수 기반으로 구현한다.
- PDF 생성 시간이 길어지거나 서버리스 실행 제한에 영향을 받을 경우, PDF 생성 기능은 별도 서버 또는 Worker로 분리할 수 있다.
