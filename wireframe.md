# 나의 이야기(My Story) 전체 요구사항 와이어프레임

> 요구사항명세서 v0.1 기준 · 텍스트 기반 IA/UI 와이어프레임

## 1. 전체 구조 및 사용자 흐름

```text
[공통]
홈 ──> 북타입 선택 ──> 마이북 생성(기본정보) ──> 안내 ──> 목차 확인/질문 생성
                                                            │
                                                            ▼
마이북 목록 <── 질문 작성 <── 진행 현황/목차 ──> 출판 현황 ──> 표지 선택 ──> PDF 생성 ──> 다운로드

[관리자]
로그인 ──> 관리자 대시보드 ──> 질문 관리
                              ├> 질문그룹 관리
                              └> 북타입 관리
```

### 공통 레이아웃

```text
┌──────────────────────────────────────────────────────────────────────┐
│ LOGO 나의 이야기       [나의 책] [새 책 만들기]              [프로필] │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│                         페이지별 콘텐츠                              │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

- 로그인/권한 기능은 2차 개발이지만, 화면 진입점과 권한 분리 구조를 둔다.
- 관리자 화면은 좌측 사이드바, 사용자 화면은 상단 내비게이션을 사용한다.

## 2. 사용자 화면

### U-01. 홈

```text
┌──────────────────────────────────────────────────────────────────────┐
│ LOGO 나의 이야기                                  [나의 책] [시작하기]│
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│                  당신의 삶을 한 권의 이야기로                        │
│        질문에 답하며 소중한 기억을 기록해 보세요.                     │
│                                                                      │
│                         [나의 책 만들기]                             │
│                                                                      │
├──────────────────────────────────────────────────────────────────────┤
│  01 질문 선택  ─────  02 답변 작성  ─────  03 PDF 출판               │
└──────────────────────────────────────────────────────────────────────┘
```

- CTA: `나의 책 만들기` → U-02.
- 로그인 사용자는 최근 마이북 카드와 `이어 쓰기`를 함께 표시할 수 있다.

### U-02. 북타입 선택 (마이북 생성 Step 1)

```text
┌──────────────────────────────────────────────────────────────────────┐
│  책 만들기                                      Step 1/4  ●○○○        │
├──────────────────────────────────────────────────────────────────────┤
│  어떤 이야기책을 만들까요?                                           │
│                                                                      │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐                  │
│  │ [표지 이미지] │ │ [표지 이미지] │ │ [표지 이미지] │                  │
│  │ 부모님 이야기 │ │ 나의 자서전   │ │ 싱글 라이프   │                  │
│  │ 설명...       │ │ 설명...       │ │ 설명...       │                  │
│  │ 질문그룹 n개  │ │ 질문그룹 n개  │ │ 질문그룹 n개  │                  │
│  └──────────────┘ └──────────────┘ └──────────────┘                  │
│                                                                      │
│                                              [다음: 기본정보 입력]   │
└──────────────────────────────────────────────────────────────────────┘
```

- 카드 선택은 단일 선택, 선택 전 다음 버튼은 비활성화.
- 선택한 북타입의 설명과 포함 질문그룹/예상 질문 수를 보여 준다.

### U-03. 기본정보 입력 (마이북 생성 Step 2)

```text
┌──────────────────────────────────────────────────────────────────────┐
│  책 만들기                                      Step 2/4  ●●○○        │
├──────────────────────────────────────────────────────────────────────┤
│  책의 기본정보를 입력해 주세요.                                     │
│                                                                      │
│  책 제목           [________________________________________]        │
│  보내는 사람       [________________________________________]        │
│  받는 사람         [________________________________________]        │
│  한 줄 소개        [________________________________________]        │
│                                                                      │
│  [이전]                                      [다음: 작성 안내 보기]  │
└──────────────────────────────────────────────────────────────────────┘
```

- 각 항목의 필수 여부와 글자 수 제한은 정책 확정 후 표시한다.
- `다음` → U-04. 이전 선택값은 유지한다.

### U-04. 작성 안내 (마이북 생성 Step 3)

```text
┌──────────────────────────────────────────────────────────────────────┐
│  책 만들기                                      Step 3/4  ●●●○        │
├──────────────────────────────────────────────────────────────────────┤
│  작성 전에 확인해 주세요.                                             │
│                                                                      │
│  ┌ 작성 방법 ─ 질문을 읽고 편안하게 답변을 작성하세요.               │
│  ├ 저장 방법 ─ 임시저장 또는 30초 자동저장이 됩니다.                 │
│  ├ 작성 시간 ─ 언제든 이어서 작성할 수 있습니다.                    │
│  └ 개인정보 ─ 작성 내용은 안전하게 보호됩니다.                      │
│                                                                      │
│  [이전]                                      [다음: 목차 확인하기]   │
└──────────────────────────────────────────────────────────────────────┘
```

### U-05. 목차 확인 및 질문 생성 (마이북 생성 Step 4)

```text
┌──────────────────────────────────────────────────────────────────────┐
│  책 만들기                                      Step 4/4  ●●●●        │
├──────────────────────────────────────────────────────────────────────┤
│  "부모님 이야기"에 포함될 질문을 확인해 주세요.                     │
│                                                                      │
│  전체 질문 120개                                                      │
│  ┌ 어린 시절 (24) ────────────────────────────────────────────────┐ │
│  │  1. 가장 오래된 기억은 무엇인가요?                               │ │
│  │  2. 어린 시절 가장 좋아했던 놀이는 무엇인가요?                   │ │
│  ├ 부모님 (30) ──────────────────────────────────────────────────┤ │
│  ├ 결혼 (22) ────────────────────────────────────────────────────┤ │
│  └ 자녀 (44) ────────────────────────────────────────────────────┘ │
│                                                                      │
│  [이전]                                         [이 질문으로 책 만들기]│
└──────────────────────────────────────────────────────────────────────┘
```

- 선택 북타입 → 연결 질문그룹 → 그룹 내 활성 질문을 순서대로 자동 생성한다.
- 생성 완료 → U-06(마이북 대시보드/진행률).

### U-06. 마이북 대시보드 / 진행 현황

```text
┌──────────────────────────────────────────────────────────────────────┐
│  < 나의 책        부모님 이야기                         [출판하기]   │
├─────────────────────┬────────────────────────────────────────────────┤
│  책 정보            │  작성 현황                                      │
│  제목               │  전체 120  |  완료 54  |  미작성 66             │
│  보내는 사람        │  [█████████░░░░░░░░░░░] 45%                     │
│  받는 사람          │                                                │
│                     │  이어서 작성                                   │
│  [책 정보 수정]     │  어린 시절 · 5번 질문                          │
│                     │  [답변 작성하기]                               │
├─────────────────────┼────────────────────────────────────────────────┤
│  목차               │  완료한 질문 / 미작성 질문 목록                 │
│  ▾ 어린 시절  8/24  │  [완료] 1. ...                [수정]           │
│  ▸ 학교생활  4/18   │  [미작성] 2. ...              [작성]           │
│  ▸ 가족      12/30  │                                                │
│  ...                │                                                │
└─────────────────────┴────────────────────────────────────────────────┘
```

- 완료/미작성 상태, 그룹별 완료 수, 전체 진행률을 표시한다.
- 목차의 질문 또는 `이어 쓰기` → U-07.
- `출판하기` → U-08.

### U-07. 질문 답변 작성

```text
┌──────────────────────────────────────────────────────────────────────┐
│  < 목차    부모님 이야기                              저장됨 14:32   │
├──────────────────────────────────────────────────────────────────────┤
│  어린 시절 · 5 / 24                                  전체 54 / 120   │
│  ──────────────────────────────────────────────────────────────────  │
│  Q. 어린 시절 가장 기억에 남는 하루는 언제인가요?                    │
│                                                                      │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │ 답변을 자유롭게 작성해 주세요.                                  │ │
│  │                                                                │ │
│  │                                                                │ │
│  └────────────────────────────────────────────────────────────────┘ │
│  (향후: 사진 · 음성 · 동영상 첨부)                                   │
│                                                                      │
│  [임시저장]                         [이전 질문] [다음 질문] [최종저장]│
└──────────────────────────────────────────────────────────────────────┘
```

- 30초마다 자동저장하며 저장 상태(`저장 중`, `저장됨`, `저장 실패`)와 최근 저장 시간을 표시한다.
- `임시저장`은 계속 작성 상태, `최종저장`은 해당 답변 완료 처리 후 대시보드 진행률을 갱신한다.
- 기존 답변 진입 시 텍스트를 채우고 `수정됨` 상태를 표시한다.

### U-08. 출판 전 작성현황 확인

```text

│                                                                      │
│  작성 현황: 전체 120 / 완료 54 / 미작성 66 / 진행률 45%              │

│                                                                      │
│  미작성 질문은 PDF에서 빈 답변으로 포함될 수 있습니다.               │
```

- 출판 버튼은 미작성 답변이 있어도 경고 후 진행 가능하도록 설계한다.
- `목차로 돌아가기` → U-06, 다음 → U-09.

```text
│                                                                      │

│  │ 책 제목      │  │ 책 제목      │  │ 책 제목      │               │
```

- 북타입 표지 이미지와 출판용 표지 선택 자산을 사용한다.
- 표지 선택 전 PDF 생성 버튼은 비활성화.

- 생성 실패 시 재시도 버튼과 오류 안내를 제공한다.

## 3. 관리자 화면

### A-01. 관리자 로그인

```text
┌──────────────────────────────────────────────┐
│                  나의 이야기 관리자           │
│                                              │
│  이메일     [____________________________]   │
│  비밀번호   [____________________________]   │
│                                              │
│                 [로그인]                     │
└──────────────────────────────────────────────┘
```

- 인증 성공 시 A-02로 이동. 일반 사용자와 관리자 권한을 분리한다.

### A-02. 관리자 공통 레이아웃 및 대시보드

```text
┌───────────────────┬──────────────────────────────────────────────────┐
│ 나의 이야기 Admin │  대시보드                          관리자 ▾       │
├───────────────────┼──────────────────────────────────────────────────┤
│ ▣ 대시보드        │  [질문 수] [질문그룹 수] [북타입 수]              │
│ □ 질문 관리       │                                                  │
│ □ 질문그룹 관리   │  최근 등록 질문                                    │
│ □ 북타입 관리     │  ┌─────────────────────────────────────────────┐ │
│ ───────────────   │  │ 질문 내용 / 그룹 / 사용 여부 / 등록일        │ │
│ □ 사용자 관리     │  └─────────────────────────────────────────────┘ │
│   (2차 개발)      │                                                  │

```

### A-03. 질문 관리 — 목록/검색

```text
┌──────────────────────────────────────────────────────────────────────┐
│  질문 관리                                             [+ 질문 등록]  │
├──────────────────────────────────────────────────────────────────────┤
│  [질문 내용 검색________________] [질문그룹 전체 ▾] [검색]          │
│                                                                      │
│  □ │ 순서 │ 질문 내용                  │ 질문그룹 │ 사용 │ 관리     │
│ ───┼──────┼────────────────────────────┼──────────┼──────┼───────── │
│  □ │  1   │ 가장 오래된 기억은...?      │ 어린시절 │ 사용 │ 수정 삭제│
│  □ │  2   │ ...                        │ 어린시절 │ 미사용│ 수정 삭제│
│                                                                      │
│  < 1 2 3 >                                                        │
└──────────────────────────────────────────────────────────────────────┘
```

- 검색 및 질문그룹 필터 제공.
- 삭제 요청 시 확인 모달을 띄우며, 사용 중 질문은 삭제 불가 안내와 비활성화 선택지를 제공한다.

### A-06. 북타입 관리 — 목록

```text
┌──────────────────────────────────────────────────────────────────────┐
│  북타입 관리                                         [+ 북타입 등록] │
├──────────────────────────────────────────────────────────────────────┤

```

### A-07. 북타입 등록/수정 및 상세

- 상세 화면은 표지, 설명, 연결 질문그룹, 자동 포함 질문 수와 질문 미리보기를 표시한다.
- 북타입 삭제 시 연결된 마이북/사용 여부를 확인하고 삭제 불가 또는 비활성 처리 정책을 안내한다.

## 4. 공통 상태 및 예외 화면

|상황|화면 처리|
|---|---|
|데이터 없음|빈 상태 메시지와 등록/생성 CTA 표시|
|폼 검증 실패|문제 입력칸 하단에 오류 메시지, 저장 차단|
|자동저장 실패|상단 상태 영역에 실패 사유와 `다시 저장` 표시|
|질문 삭제 불가|사용 중인 질문임을 안내하고 `미사용 처리` 제공|
|PDF 생성 실패|실패 안내, 재시도, 이전 출판 단계로 돌아가기 제공|
|권한 없음|권한 없음 안내 후 허용된 첫 화면으로 이동|
